First release of CapITV.

- `capitv-0.1.0.apk` / `capitv.apk`: the CapITV launcher (Android TV 11+). No INTERNET permission.
- Install it with `provision/capitv-provision.sh <box-ip>` (it downloads this release with `gh` if you have no local build), or `adb install capitv.apk`.
- `SHA256SUMS.txt`: checksums.

See the README quick start and docs/SUPERVISION.md.
